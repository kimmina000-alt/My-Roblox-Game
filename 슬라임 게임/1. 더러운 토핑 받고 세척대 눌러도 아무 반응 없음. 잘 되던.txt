🔴 3. Topping 여러 개 규칙

- 서로 겹쳐도 되는지

Topping = 구슬

## 그리고 현실 인기도를 어떻게 사용할 거냐

여기가 상당히 중요해.

나는 **`현실 인기도`라는 필드를 게임 데이터에 절대 넣지 않는 것**을 추천해.

대신 개발할 때만 다음처럼 판단하는 거야.

**현실 자료 → 디자인 판단 → 게임 Rarity / Gold**

예를 들어:

**Bingsu Beads**

- 현실 존재 ✔
- 실제 슬라임에서 흔히 사용 ✔

- 관련 상품/공급품 다수 존재 ✔ [Dope Slimes LLC](https://dopeslimes.com/pages/suppliescollection?utm_source=chatgpt.com)
- 커뮤니티에서도 선호 확인 ✔ [Reddit](https://www.reddit.com/r/Slime/comments/1sqiiub/qotd_which_addins_do_you_love_most_in_slime/?utm_source=chatgpt.com)

→ **Rare\~Epic**

반면 그냥 작은 별 스프링클:

- 현실에서 흔함
- 시각적 효과는 좋음
- 촉감 기여도 낮음

→ **General**

그리고 Crystal Beads 같은 경우:

- 시각적 가치 높음
- 촉감도 있음
- 희소한 느낌
- Mythical 연출에 적합

→ **Mythical**

즉,

**현실 인기도 ≠ 게임 능력치**

하지만

**현실 인기도 + 희소성 + 촉감 + ASMR + 시각적 가치 + 테마성 → 게임 등급 결정**

Base 중복
- Sherbet으로 진행
- Jelly Cube / Topping : 이건 뭐 검수하면 되는 거임

-  Cloud로 진행
- Base의 Glossy와 Glossy & Glitter의 Glossy 역할 중복 -> Base에서 삭제하고 글로시 효과로 가자

Topping 등급
- 특히 L부터 높은 등급이라는 새 규칙에 현재 Rarity가 제대로 맞는지. ->Rarity가 먼 소린지 모르겠음 L부터 높은 등급 괜찮음


Fragrance
- 기존 30분 → 네가 예전에 검토했던 15분 중 어느 쪽으로 갈지. -> 15분
- Income/Speed 효과 수치. ->  네가 적당하게 배분한 거 아님?

Dye
- White를 Rare로 올리는 것. -> 올려
- 혼합 결과를 고정 레시피로 둘지, 색상 거리 계산만으로 만들지. -> 무슨 소리임? 
- 혼합 결과를 Wakppu에서 직접 얻을 수 있게 할지. -> 어떻게 하는 게 좋을까

Glossy & Glitter
- 이번에 처음으로 하나로 합쳤기 때문에 GG011~GG034는 특히 검수 필요. -> 니가 더 화려한 걸 높은 등급으로 잘했껬지. 널 믿어.
- Glossy/Glitter 동시 적용 불가는 현재 반영. ->  okay

Wakppu 등장 여부
- 내가 위 표에서 O/X를 임시 배정했으므로 네가 실제 획득 구조와 맞는지 확인 필요.
-> 베이스는 뺄까? 뭐가 더 재미있겠니 

Rebirth 비용
- 실제 발걸음 빈도와 9 Worker 운영을 기준으로 최종 시뮬레이션하기 전의 밸런스 초안.
- 특히 R1~R3가 실제 플레이에서 너무 빨리/느리게 오는지 확인 필요. -> 해 봐야 알지 내가 어케 알아 니가 가상으로 굴려 보면 니가 더 잘 알 듯
