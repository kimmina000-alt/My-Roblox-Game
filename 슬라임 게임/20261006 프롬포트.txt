① 최종 확정 기획
1. 게임의 기본 구조
플레이어가 자신의 개인 영역에서 슬라임을 제작하고 관리하는 게임이다.
주요 흐름은 다음과 같다.
Base 획득
↓
Topping 획득
↓
Topping 세척
↓
재료 진열/관리
↓
Kneading Table에서 슬라임 제작
↓
Dye / Fragrance / Glossy & Glitter / Topping으로 꾸미기
↓
Gold 획득
↓
패드 및 콘텐츠 확장
↓
환생
↓
새로운 보상 / Aura / 가챠 구역 해금

2. 환생 시스템
환생 조건
환생하려면 다음 두 조건을 모두 만족해야 한다.
조건 1
지정된 필수 Topping을 보유하고 있어야 한다.
첫 번째 필수 Topping:
구슬 토핑

향후 환생 횟수가 증가하면 요구 Topping이 변경될 수 있으므로 환생 조건은 코드 여러 곳에 직접 작성하지 않고 중앙 설정 데이터로 관리한다.
조건 2
필요한 Gold를 보유해야 한다.
환생하기 전에 현재 보유 Gold가 초기화된다는 경고를 표시한다.
환생 시 초기화
환생 시 초기화되는 것은 오직 CurrentGold다.
CurrentGold → 0

다음 항목들은 환생해도 유지한다.
- 모든 보유 아이템
- Dirty Topping
- Base
- Topping
- Dye
- Fragrance
- Glossy & Glitter
- 인벤토리
- 해금한 패드
- 패드 위 Base
- 패드 위 Topping
- 가챠 구역 해금 상태
- 획득한 Aura
- 기타 영구 진행 데이터
특히 중요
환생했다고 해서 패드 위의 Base와 Topping을 회수하거나 제거하면 안 된다.
환생 전:
pad_2
└─ Base + Topping

이었다면 환생 후에도:
pad_2
└─ 같은 Base + Topping 유지

되어야 한다.
3. TotalGold와 CurrentGold 분리
Gold는 두 종류의 데이터로 관리한다.
CurrentGold
현재 사용할 수 있는 Gold.
환생하면:
CurrentGold = 0

TotalGold
게임을 플레이하면서 누적해서 획득한 전체 Gold.
환생해도 유지한다.
Roblox Leaderboard의 Gold에는 TotalGold를 표시한다.
따라서 환생 직후:
CurrentGold = 0
TotalGold = 기존 누적값 유지

가 된다.
4. 환생 보상
환생할 때:
유지
- 노동자 최대 수용 인원 +1
- 새로운 Aura 획득
- 가챠 구역 1개 해금
삭제
- 노동자 수익 증가 %
노동자 수익을 환생 횟수에 따라 % 증가시키는 시스템은 더 이상 사용하지 않는다.
5. Aura
환생할 때마다 새로운 Aura를 획득한다.
기존에 획득했던 Aura도 모두 유지한다.
오라 켜기 버튼을 누르면 보유 Aura 목록 UI가 표시된다.
플레이어는:
- Aura 장착
- Aura 해제
- 다른 Aura 선택
이 가능해야 한다.
6. 가챠 구역
환생할 때마다 다음 가챠 구역 하나가 해금된다.
예:
환생 1회 → 가챠 구역 1 해금
환생 2회 → 가챠 구역 2 해금
환생 3회 → 가챠 구역 3 해금

이미 해금한 가챠 구역은 환생해도 다시 잠기지 않는다.
7. 무료 캡슐
무료 캡슐은 자동으로 여러 개가 쌓이는 방식이 아니다.
플레이어 접속 시점부터 20분 타이머가 시작된다.
접속
↓
20분 타이머
↓
20분 완료
↓
무료 캡슐 얻기 버튼 활성화

20분이 완료되어도 플레이어가 받지 않으면 완료 상태를 유지한다.
추가 20분 타이머를 시작하거나 무료 캡슐을 중첩해서 쌓지 않는다.
플레이어가 수령하면:
무료 캡슐 수령
↓
새로운 20분 타이머 시작

무료 캡슐 열기 버튼을 누르면 관련 GUI를 연다.
8. 가챠 머신
가챠 머신은 플레이어 개인 영역이 아니라 공용 공간에 배치한다.
모든 플레이어가 사용할 수 있다.
머신 근처에 갔다고 확률창을 자동으로 표시하지 않는다.
머신 옆의 작은 ! 버튼을 누르면 확률 정보창을 표시한다.
가챠 이용 과정
머신에서 E를 누른다.
바로 보상을 주는 것이 아니라 가챠 머신 GUI가 열린다.
GUI 내부에서:
1. 캡슐들이 머신 안에서 움직임
2. 하단 손잡이 영역을 클릭
3. 손잡이가 회전
4. 캡슐이 하단 오른쪽 배출구에서 나옴
5. 캡슐이 중앙으로 이동
6. 캡슐 확대
7. 캡슐 회전
8. 캡슐 개봉
9. 밝은 빛 효과
10. 약 0.5초간 보상 표시

9. Base Pump
Base를 얻는 기본 Pump 시스템이 존재한다.
Pump에는:
- 현재 보유량
- 최대 용량
이 존재한다.
그리고 플레이어가 Pump 가까이 가지 않아도 현재 양을 확인할 수 있도록 Pump 블록 위에 표시 UI를 배치한다.
표시 예:
BASE PUMP

███████░░░

72 / 100

또는 비슷한 형태의 게이지.
반드시 다음 정보를 보여준다.
- 현재 보유량
- 최대 용량
- 현재량 / 최대량
- 게이지
Pump UI 거리 처리
플레이어가 Pump에서 멀리 떨어져 있어도 확인할 수 있어야 한다.
예를 들어 플레이어가 다른 곳에서 Topping을 세척하고 있어도 Pump 잔량을 확인할 수 있어야 한다.
다만 너무 멀리 떨어졌을 때 UI가 화면을 방해하지 않도록:
- 거리에 따라 자연스럽게 작아지거나
- 일정 거리 이상에서 숨겨지는 방식
은 사용할 수 있다.
단, 기존처럼 Pump 바로 앞에 가야만 표시되는 방식으로 제한하면 안 된다.
Pump 용량 업그레이드 대비
향후 Pump 용량 업그레이드가 추가될 가능성이 있다.
따라서 최대 용량을 UI에 하드코딩하지 않는다.
예:
현재량 72
최대 용량 100
→ 72 / 100

업그레이드 후:
현재량 72
최대 용량 200
→ 72 / 200

처럼 자동으로 바뀌어야 한다.
게이지 역시:
CurrentAmount / MaxCapacity

를 기준으로 자동 계산한다.
10. 다섯 종류 진열장
진열장은 다음 다섯 종류다.
- Base
- Dye
- Fragrance
- Glossy & Glitter
- Topping
각 아이템은 자신의 카테고리에 맞는 진열장에만 넣을 수 있다.
진열장 사용 규칙
아무것도 들고 있지 않음:
→ 자신의 진열장을 클릭하면 진열장 UI가 열린다.
맞는 카테고리의 아이템을 들고 있음:
→ 해당 진열장 UI가 열린다.
틀린 카테고리의 아이템을 들고 있음:
→
맞는 진열장이 아닙니다

표시.
그리고 진열장 UI를 열지 않는다.
예:
Dye를 들고
Base 진열장 클릭

→ 맞는 진열장이 아닙니다

Topping을 들고
Topping 진열장 클릭

→ 정상 작동

각 플레이어는 자기 영역의 진열장만 사용할 수 있다.
다른 플레이어에게는 진열장 상호작용 Prompt/버튼이 보이지 않아야 한다.
진열장 내부 아이템 위치는 변경/교체할 수 있어야 한다.

13. 회수 삽
실제 삽 Tool을 인벤토리에 지급하지 않는다.
대신:
회수 삽 받기

버튼을 사용한다.
버튼을 누르면 회수 모드 ON.
회수 모드가 켜진 상태에서 Base가 있는 패드를 클릭하면 Base를 회수한다.

14. Kneading Table
[첨부 영상] 반죽대의 중앙 3D 슬라임 조작 참고 영상입니다. 특히 마우스로 슬라임을 잡아당겼을 때 해당 지점이 따라 늘어나는 느낌, 슬라임의 탄성/변형, 마우스 드래그에 따른 움직임을 참고해서 구현해 주세요. 영상의 특정 게임을 그대로 복제하는 것이 아니라 조작감과 물리적 움직임을 참고해 주세요.
현재 보유하고 있는 아이템을 목록에서 우선 표시한다.
현재 보유 아이템을 찾기 위해 오른쪽으로 계속 스크롤해야 하는 문제를 해결한다.
사용 가능한 카테고리:
- Base
- Topping
- Dye
- Fragrance
- Glossy & Glitter
중앙 3D 슬라임에 선택한 아이템을 적용한다.
Topping 배치
Topping은 중앙 3D 슬라임에 원하는 위치를 클릭하여 자유롭게 배치한다.
슬라임 패드에서 Topping을 배치하는 방식과 유사하게 만든다.
3D 슬라임 조작
왼쪽 클릭 + 드래그:
→ 클릭한 지점을 중심으로 슬라임을 늘린다.
오른쪽 클릭 + 드래그:
→ 드래그 방향에 따라 슬라임을 회전한다.
15. Dye 색상 조합
Dye는 삼원색을 기본으로 한다.
예:
빨강 + 노랑 → 주황
노랑 + 파랑 → 초록
파랑 + 빨강 → 보라

하지만 각각의 조합을 일일이 하드코딩하지 않는다.
Dye마다 색상 데이터를 가지고 있도록 한다.
두 Dye를 섞으면 색상값을 이용하여 결과 색상을 계산한다.
그리고 계산된 결과 색상과 현재 존재하는 Dye의 색상을 비교하여 가장 가까운 기존 Dye를 찾는다.
최종 결과는 가장 가까운 기존 Dye를 사용한다.
즉:
Dye A
+
Dye B
↓
색상 계산
↓
결과 색상
↓
기존 Dye 색상과 비교
↓
가장 가까운 Dye 검색
↓
그 Dye 사용

색상 조합을 하나하나 직접 등록하지 않는다.
새로운 Dye가 추가되어도 기존 자동 계산 시스템을 그대로 사용할 수 있어야 한다.
16. Fragrance

예:

↓
복숭아 아이콘이 슬라임 위로 떠오름
↓
점점 투명해짐
↓
사라짐

향기를 시각적으로 표현하는 용도만 사용한다.
17. Glossy & Glitter

추가 능력치 버프는 없다.

- 필요한 CurrentGold 보유

CurrentGold = 0
